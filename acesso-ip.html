Acesso remoto somente por IP

Diagnóstico básico para entender se um endereço parece ser local ou público. Esta ferramenta não verifica se o celular está realmente acessível.

Verificar endereço IP

Digite um endereço IPv4 para analisar.
Limite importante: um IP público não garante que o celular aceite conexões de entrada. Muitas operadoras móveis usam CGNAT; além disso, uma página web não consegue transformar o próprio celular em servidor escutando numa porta de rede. Por isso, digitar o IP do telefone remoto, sozinho, não abre a câmera.

O que funciona para o seu caso

  1. IP direto: só funciona quando o transmissor executa um serviço de vídeo acessível, o IP é roteável e a porta é permitida pelo firewall. Não é o caso do transmissor web atual.
  2. VPN privada: conecte os dois aparelhos à mesma VPN e use um endereço VPN estável. Ainda será necessário que o transmissor ofereça um endpoint de vídeo; a página web atual não abre uma porta de servidor.
  3. Internet móvel sem configurar portas: use WebRTC com sinalização e um servidor TURN de confiança para redes que bloqueiam conexão direta. Para dispensar códigos, o próximo desenvolvimento deve adicionar contas autenticadas e um nome de dispositivo pareado, em vez de fingir que o IP público identifica o aparelho.

Recomendação: para a exigência “digitar só o IP” em qualquer rede móvel, a implementação confiável requer um aplicativo Android nativo ou um serviço de vídeo no transmissor, mais uma VPN ou infraestrutura pública autenticada. Não exponha uma câmera sem autenticação.
