Como funciona à distância

• Na mesma rede: use o IP local da câmera.

• Fora de casa: prefira VPN (por exemplo, uma VPN configurada nos dois lados) ou o serviço remoto seguro do fabricante.

• RTSP: muitos navegadores não reproduzem RTSP diretamente; é necessário um gateway que converta o fluxo para HLS/WebRTC.

• HTTPS: uma página HTTPS pode bloquear fluxos HTTP por conteúdo misto. Use HTTPS válido no fluxo ou uma origem segura.

Use somente câmeras e redes para as quais você tem autorização. As configurações salvas ficam neste navegador.
